You need to add a new "HKU DAO" system (DAO ID 2.3) while retaining the existing "Pui Ching Road" system (DAO ID 2.2). In other words, you need to use the Pui Ching DAO/road code as a base, copy it, and modify it to become Hong Kong Main Road.
